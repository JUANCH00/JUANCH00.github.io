# TagList

Lista de tecnologías como etiquetas rectas con borde `line-strong`, en `meta` a 12px (antes 10.5px).

- No interactiva: borde decorativo, texto `text-dim` (≥ 4.9:1).
- Máximo 5 o 6 por proyecto; si hay más, las principales.
- El consumidor aporta: `items` y un `aria-label` para la lista.
